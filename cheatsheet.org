* Create a Hugo blog post

#+attr_latex: :booktabs t :align @{}p{0.23\linewidth}p{0.25\linewidth}p{0.46\linewidth}@{}
| Action          | Shortcut        | Command / next step                                      |
|-----------------+-----------------+----------------------------------------------------------|
| New post        | =C-c n n h=     | =org-capture= → =h=; enter a title.                        |
| Finish capture  | =C-c C-c=       | =org-capture-finalize=; jump to the new post.              |
| Cancel capture  | =C-c C-k=       | =org-capture-kill=                                        |
| Export this post | =C-c C-e H H=  | =org-hugo-export-wim-to-md= (uppercase H).                 |
| Change status   | =C-c C-t=       | =org-todo=; choose =DONE= when ready, then export again.   |

Fill in the description before finishing capture; replace =<write here>= with
the body afterward. Export with point inside the post. =TODO= / =DRAFT= mean
draft; =DONE= means non-draft. Export writes Markdown; it does not deploy.

*Source:* under =Ideas= in
=~/Personal/websites/zzamboni.org/content-org/zzamboni.org=.
The template supplies an ID and a =YYYY-MM-DD-title-slug= bundle, exporting to
=content/post/<bundle>/index.md=.

*Check the property drawer:* =EXPORT_HUGO_CUSTOM_FRONT_MATTER= defaults to
=:featured_image /images/tram-zurich.jpg :toc false=; adjust for the post.

* Insert images into posts or Org documents

Place point beneath the appropriate heading, inside the post for Hugo.

#+attr_latex: :booktabs t :align @{}p{0.23\linewidth}p{0.25\linewidth}p{0.46\linewidth}@{}
| Action          | Shortcut        | Command / next step                                      |
|-----------------+-----------------+----------------------------------------------------------|
| Paste image     | =C-y=           | =zz/org-smart-yank=; enter a filename.                     |
| Force text yank | =C-u C-y=       | =org-yank= via the smart-yank helper.                     |
| Copy image file | =C-c C-a c=     | =org-attach= → copy; select the file.                     |
| Download image  | =C-c C-a u=     | =org-attach-url=; enter the direct image URL.              |
| Insert link     | =C-c C-l=       | =org-insert-link=; select the stored attachment.           |
| Toggle previews | =C-c C-i=       | =org-toggle-inline-images=                               |

*Clipboard:* copy the image itself. In graphical Emacs, smart yank uses
=yank-media= for PNG/JPEG/WebP/GIF; otherwise it uses =org-yank=.
Use =M-x yank-media= to invoke media paste explicitly.

*File or URL:* after attaching, insert the stored link with =C-c C-l=.
Leave the description empty to display the image. Dragging an image file
into the buffer also attaches it automatically.

*Storage:* =attachments/= beside the Org file, partitioned by ID; child
headings inherit the post's ID. Keep attachments with the source. Links
look like =[[attachment:photo.png]]=. Export the post again after changes.

*Previews:* also =C-c TAB= or =C-c C-x C-v=. The 300-pixel buffer preview
limit does not set the exported image size.
