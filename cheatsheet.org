*Non-Evil bindings.* =C-= Ctrl · =M-= Alt/Meta. Run commands with =M-x=. Documents tasks according to [[https://github.com/zzamboni/dot-doom][my personal configuration]], may not match defaults.

* Create a Hugo blog post

| Action              | Shortcut    | Command / next step                                   |
|---------------------+-------------+-------------------------------------------------------|
| New post            | =C-c n n h=   | =org-capture= → =h= — enter a title.                      |
| Finish capture      | =C-c C-c=     | =org-capture-finalize= — jump to the new post.          |
| Cancel capture      | =C-c C-k=     | =org-capture-kill=                                      |
| Export current post | =C-x C-s=     | =save-buffer= (=org-hugo-auto-export= is enabled).        |
|                     | =C-c C-e H H= | =org-hugo-export-wim-to-md=                             |
| Export all posts    | =C-c C-e H A= | Review changes before committing!                     |
| Change status       | =C-c C-t=     | =org-todo= — choose =DONE= when ready, then export again. |

Fill in the description before finishing capture; replace =<write here>= with the body afterward. Export with point inside the post. =TODO= / =DRAFT= mean draft; =DONE= means non-draft. Export writes Markdown; it does not deploy.

*Source:* under =Ideas= in =~/Personal/websites/zzamboni.org/content-org/zzamboni.org=. The template supplies an ID and a =YYYY-MM-DD-title-slug= bundle, exporting to =content/post/<bundle>/index.md=.

*Check the property drawer:* =EXPORT_HUGO_CUSTOM_FRONT_MATTER= defaults to =:featured_image /images/tram-zurich.jpg :toc false= — adjust for the post.

* Insert images into posts or Org documents

Place point beneath the appropriate heading, inside the post for Hugo.

| Action          | Shortcut    | Command / next step                             |
|-----------------+-------------+-------------------------------------------------|
| Paste image     | =C-y=         | =zz/org-smart-yank= — enter a filename.           |
| Force text yank | =C-u C-y=     | =org-yank= via the smart-yank helper.             |
| Copy image file | =C-c C-a c=   | =org-attach= → copy; select the file.             |
| Download image  | =C-c C-a u=   | =org-attach-url= — enter the direct image URL.    |
| Insert link     | =C-c C-l=     | =org-insert-link= — select the stored attachment. |
| Toggle previews | =C-c C-i=     | =org-toggle-inline-images=                        |
|                 | =C-c TAB=     |                                                 |
|                 | =C-c C-x C-v= |                                                 |

*Clipboard:* copy the image itself. In graphical Emacs, smart yank uses =yank-media= for PNG/JPEG/WebP/GIF; otherwise it uses =org-yank=. Use =M-x yank-media= to invoke media paste explicitly.

*File or URL:* after attaching, insert the stored link with =C-c C-l=. Leave the description empty to display the image. Dragging an image file into the buffer also attaches it automatically.

*Storage:* =attachments/= beside the Org file, partitioned by ID; child headings inherit the post's ID. Keep attachments with the source. Links look like =[[attachment:photo.png]]=. Export the post again after changes.

*Image Previews:* The 300-pixel buffer preview limit does not set the exported image size.

* Filter and focus on Org headings

Use a sparse tree to find draft posts in the current Org file, then narrow
to one post for distraction-free editing.

| Action                   | Shortcut  | Command / next step                                                 |
|--------------------------+-----------+---------------------------------------------------------------------|
| Show draft headings      | =C-c / t=   | =org-show-todo-tree= — enter =DRAFT=; ancestors remain visible.         |
| Narrow to one subtree    | =C-x n s=   | =org-narrow-to-subtree= — show only the current heading and children. |
| Restore entire buffer    | =C-x n w=   | =widen= — remove narrowing.                                           |
| Edit in separate buffer  | =C-c C-x b= | =org-tree-to-indirect-buffer= — edit subtree in an indirect buffer.   |
| Reset outline visibility | =S-TAB=     | =org-shifttab= — cycle global visibility after sparse-tree filtering. |

*Workflow:* use =C-c / t= to find =DRAFT= headings; move to the desired heading and use =C-x n s= to focus on its subtree. Use =C-x n w= afterward. Alternatively, =C-c C-x b= opens an indirect buffer that shares the original text, so edits also update the source buffer.
