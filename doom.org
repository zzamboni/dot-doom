* Maintaining this configuration

** Files and load order

Edit this file, then run =C-c C-v t= (=org-babel-tangle=). Do not edit the
generated files directly. Package declarations stay beside their configuration
and explicitly select =packages.el=; other Lisp defaults to =config.el=.

| Output | Purpose | Apply changes |
|--------+---------+---------------|
| =init.el= | Enabled Doom modules and flags | =doom sync=, restart |
| =packages.el= | Additional packages and recipe overrides | =doom sync=, restart |
| =config.el= | Personal settings, commands, and bindings | Restart or =M-x doom/reload= |
| =~/.slynkrc= | Sly server setting for Common Lisp | Restart the Sly connection |

The Common Lisp section also tangles =~/.slynkrc= outside this repository.
=custom.el= holds Emacs-managed settings, including trusted themes and file-local
variables; keep those separate from this source.

Set variables needed during package initialization before loading the package.
Use =after!= or =use-package!= for settings that depend on its definitions.
Keep structure setters and Transient macros inside the existing deferred forms:
expanding them too early can break startup after an upgrade.

** Dependencies and upgrades

This configuration is reviewed against Emacs 30.2, Org 9.8.9, and org-gtd 4.0.7.
Doom modules live in =~/.emacs.d/sources/doom+/modules/= on this installation.
Their =.doommodule=, =packages.el=, and =config.el= describe the installed behavior;
older online examples may reference removed flags such as Org's =+hugo=.

Keep the local =org-cv= and =ox-leanpub= development repositories available at
the paths in their recipes. External tools include =tectonic=, =typst=,
=elvish=, =pandoc=, and the compilers/interpreters used by enabled language
modules. The Reveal browser helper and Outlook capture require macOS.

After edits, tangle, run =git diff --check=, inspect the generated diff, and test
a fresh Emacs startup plus the affected commands. A package upgrade can require
=doom sync -b= to rebuild stale bytecode; do not add compatibility shims before
checking the installed sources and build state.

* Navigation and editing

** Buffers, search, and undo

=C-x b= combines file buffers and recent files; =C-x C-b= lists buffers.
The [[https://github.com/abo-abo/swiper/pull/2687][Counsel override]] still matters: the installed implementation does not
abbreviate buffer paths before deduplication. Track visits so recent files
follow navigation order.

=C-s= uses Doom's buffer search; =C-c s r/q= perform visual regexp replacement.
=C-c C-g= opens Magit. =C-?= redoes changes, =M-g g= and =M-g M-g= jump to lines,
and =M-g o= selects an outline heading.

#+begin_src emacs-lisp
(map! "C-x b"   #'counsel-buffer-or-recentf
  "C-x C-b" #'counsel-switch-buffer)

(defun zz/counsel-buffer-or-recentf-candidates ()
  "Return candidates for `counsel-buffer-or-recentf'."
  (require 'recentf)
  (recentf-mode)
  (let ((buffers
         (delq nil
               (mapcar (lambda (b)
                         (when (buffer-file-name b)
                           (abbreviate-file-name (buffer-file-name b))))
                       (delq (current-buffer) (buffer-list))))))
    (append
     buffers
     (cl-remove-if (lambda (f) (member f buffers))
                   (counsel-recentf-candidates)))))

(advice-add #'counsel-buffer-or-recentf-candidates
            :override #'zz/counsel-buffer-or-recentf-candidates)
#+end_src

** Matching parentheses with =%=

Inspired by [[https://www.emacswiki.org/emacs/NavigatingParentheses][NavigatingParentheses]]. After navigation commands, =%= jumps to the matching delimiter using Smartparens.
Otherwise it inserts a literal percent sign. Keep the command whitelist explicit
so normal typing and repeated jumps retain their existing behavior.

#+begin_src emacs-lisp
(after! smartparens
  (defun zz/goto-match-paren (arg)
    "Go to the matching paren/bracket, otherwise (or if ARG is not
    nil) insert %.  vi style of % jumping to matching brace."
    (interactive "p")
    (if (not (memq last-command '(set-mark
                                  cua-set-mark
                                  zz/goto-match-paren
                                  down-list
                                  up-list
                                  end-of-defun
                                  beginning-of-defun
                                  backward-sexp
                                  forward-sexp
                                  backward-up-list
                                  forward-paragraph
                                  backward-paragraph
                                  end-of-buffer
                                  beginning-of-buffer
                                  backward-word
                                  forward-word
                                  mwheel-scroll
                                  backward-word
                                  forward-word
                                  mouse-start-secondary
                                  mouse-yank-secondary
                                  mouse-secondary-save-then-kill
                                  move-end-of-line
                                  move-beginning-of-line
                                  backward-char
                                  forward-char
                                  scroll-up
                                  scroll-down
                                  scroll-left
                                  scroll-right
                                  mouse-set-point
                                  next-buffer
                                  previous-buffer
                                  previous-line
                                  next-line
                                  back-to-indentation
                                  doom/backward-to-bol-or-indent
                                  doom/forward-to-last-non-comment-or-eol
                                  )))
        (self-insert-command (or arg 1))
      (cond ((looking-at "\\s\(") (sp-forward-sexp) (backward-char 1))
            ((looking-at "\\s\)") (forward-char 1) (sp-backward-sexp))
            (t (self-insert-command (or arg 1))))))
  (map! "%" 'zz/goto-match-paren))
#+end_src

** Clipboard images and attachments

Use native =org-attach= and =yank-media=. =C-y= pastes clipboard images with a
filename prompt, otherwise it calls =org-yank=; a prefix argument forces normal
yanking. Inherit attachment IDs so one post can share its attachment directory.

Org 9.8's image handler now passes a filename description to the link formatter.
The scoped advice removes that description only while pasting images, preserving
bare =[[attachment:image.png]]= links for figure export. Ordinary attachment links
keep their descriptions. Recheck this private handler when upgrading Org.

#+begin_src emacs-lisp
(after! org
  (setq org-attach-use-inheritance t
        org-attach-preferred-new-method 'id
        org-attach-auto-tag nil
        org-yank-dnd-method 'attach
        org-yank-image-file-name-function #'org-yank-image-read-filename
        org-image-actual-width nil
        org-image-max-width 300))

(after! org
  (defun zz/org-yank-image-without-description (handler &rest args)
    "Run image HANDLER with bare links suitable for inline image export."
    (let ((formatter (symbol-function 'org-link-make-string-for-buffer)))
      (cl-letf (((symbol-function 'org-link-make-string-for-buffer)
                 (lambda (link &optional _description interactive-p)
                   (funcall formatter link nil interactive-p))))
        (apply handler args))))
  (advice-add 'org--image-yank-media-handler :around
              #'zz/org-yank-image-without-description))

(defun zz/org-smart-yank (&optional arg)
  "Yank normally, or use `yank-media' for clipboard images."
  (interactive "P")
  (let ((targets (and (display-graphic-p)
                      (gui-get-selection 'CLIPBOARD 'TARGETS))))
    (if (and (not arg)
             (seq-some
              (lambda (type)
                (string-match-p
                 "^image/\\(png\\|jpeg\\|webp\\|gif\\)$"
                 (format "%s" type)))
              (append targets nil)))
        (yank-media)
      (org-yank arg))))

(after! org
  (map! :map org-mode-map
    "C-y" #'zz/org-smart-yank))
#+end_src

** Links between headings

=C-c l l h= selects a heading with Counsel. Store readable =CUSTOM_ID= values
and insert local =#id= links rather than UUID links. Existing IDs are retained;
the title-derived format is intentionally unchanged for published anchors.

#+begin_src emacs-lisp
(map! :after counsel :map org-mode-map
  "C-c l l h" #'counsel-org-link)

(after! counsel
  (setq counsel-outline-display-style 'title))

(after! org-id
  ;; Do not create ID if a CUSTOM_ID exists
  (setq org-id-link-to-org-use-id 'create-if-interactive-and-no-custom-id))

(defun zz/make-id-for-title (title)
  "Return an ID based on TITLE."
  (replace-regexp-in-string "[^[:alnum:]]" "-" (downcase title)))

(defun zz/org-custom-id-create ()
  "Create and store CUSTOM_ID for current heading."
  (let* ((title (or (nth 4 (org-heading-components)) ""))
         (new-id (zz/make-id-for-title title)))
    (org-entry-put nil "CUSTOM_ID" new-id)
    (org-id-add-location new-id (buffer-file-name (buffer-base-buffer)))
    new-id))

(defun zz/org-custom-id-get-create (&optional where force)
  "Get or create CUSTOM_ID for heading at WHERE.

If FORCE is t, always recreate the property."
  (org-with-point-at where
    (let ((old-id (org-entry-get nil "CUSTOM_ID")))
      ;; If CUSTOM_ID exists and FORCE is false, return it
      (if (and (not force) old-id (stringp old-id))
          old-id
        ;; otherwise, create it
        (zz/org-custom-id-create)))))

;; Now override counsel-org-link-action
(after! counsel
  (defun counsel-org-link-action (x)
    "Insert a link to X.

X is expected to be a cons of the form (title . point), as passed
by `counsel-org-link'.

If X does not have a CUSTOM_ID, create it based on the headline
title."
    (let* ((id (zz/org-custom-id-get-create (cdr x))))
      (org-insert-link nil (concat "#" id) (car x)))))
#+end_src

           (subtree (and (member "--subtree" args) t))
           (visible (and (member "--visible" args) t))

#+begin_src emacs-lisp
(defun zz/org-current-headline-number ()
  "Get the numbering of the innermost headline which contains the
cursor. Returns nil if the cursor is above the first level-1
headline, or at the very end of the file. Does not count
headlines tagged with :noexport:"
  (require 'org-num)
  (let ((org-num--numbering nil)
        (original-point (point)))
    (save-mark-and-excursion
      (let ((new nil))
        (org-map-entries
         (lambda ()
           (when (org-at-heading-p)
             (let* ((level (nth 1 (org-heading-components)))
                    (numbering (org-num--current-numbering level nil)))
               (let* ((current-subtree (save-excursion (org-element-at-point)))
                      (point-in-subtree
                       (<= (org-element-property :begin current-subtree)
                           original-point
                           (1- (org-element-property :end current-subtree)))))
                 ;; Get numbering to current headline if the cursor is in it.
                 (when point-in-subtree (push numbering
                                              new))))))
         "-noexport")
        ;; New contains all the trees that contain the cursor (i.e. the
        ;; innermost and all its parents), so we only return the innermost one.
        ;; We reverse its order to make it more readable.
        (reverse (car new))))))

(defun zz/refresh-reveal-prez ()
  ;; Export the file
  (org-re-reveal-export-to-html)
  (let* ((slide-list (zz/org-current-headline-number))
         (slide-str (string-join (mapcar #'number-to-string slide-list) "-"))
         ;; Determine the filename to use
         (file (concat (file-name-directory (buffer-file-name))
                       (org-export-output-file-name ".html" nil)))
         ;; Final URL including the slide number
         (uri (concat "file://" file "#/slide-" slide-str))
         ;; Get the document title
         (title (cadar (org-collect-keywords '("TITLE"))))
         ;; Command to reload the browser and move to the correct slide
         (cmd (concat
               "osascript -e \"tell application \\\"Brave\\\" to repeat with W in windows
set i to 0
repeat with T in (tabs in W)
set i to i + 1
if title of T is \\\"" title "\\\" then
  reload T
  delay 0.1
  set URL of T to \\\"" uri "\\\"
  set (active tab index of W) to i
end if
end repeat
end repeat\"")))
    ;; Short sleep seems necessary for the file changes to be noticed
    (sleep-for 0.2)
    (call-process-shell-command cmd)))
#+end_src

** Chezmoi and Magit

Include the Chezmoi Magit extension in the package recipe and load it through

integration.

#+begin_src emacs-lisp :tangle packages.el

  :recipe (:files (:defaults "extensions/chezmoi-magit.el")))
#+end_src

  :after magit
  :commands chezmoi-magit-status)
